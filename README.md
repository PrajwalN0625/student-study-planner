# Student Study Planner 📚

A simple web application built using Python and Flask to help students organize their study tasks.

## Features

- Add new study tasks
- Mark tasks as completed
- Undo completed tasks
- Delete tasks
- Save tasks permanently using SQLite
- Simple and responsive user interface

## Technologies Used

- Python
- Flask
- HTML
- CSS
- SQLite

## How to Run

1. Clone or download this repository.
2. Open the project folder in a terminal.
3. Create and activate a virtual environment:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

4. Install Flask:

   ```bash
   pip install flask
   ```

5. Start the application:

   ```bash
   python app.py
   ```

6. Open `http://127.0.0.1:5000` in your browser.

## Learning Goals

This project demonstrates basic web development, Flask routing, HTML forms, CSS styling, and database operations using SQLite.
